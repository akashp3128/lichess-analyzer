This is a SaaS chess analysis app built on Next.js with Prisma.

Milestones:
- Milestone 1: UI polish with neutral glass + dark mode
- Milestone 2: Plan Details modal before subscribe
- Milestone 3: Plans Dashboard with quota visuals

Pricing Plans:
- Free: $0/mo, 5 analyses/mo
- Pro: $20/mo, 1000 analyses/mo
- Coach: $40/mo, 5000 analyses/mo
- Yearly discounts available (25% off)

API Endpoints:
- GET /api/billing/plans
- POST /api/billing/subscribe
- GET /api/billing/usage
- POST /api/billing/upgrade

Frontend:
- /plans page with Framer-inspired UI
- Plans dashboard at /plans-dashboard (quota visuals)

Dark mode styling: neutral glass with obsidian glass vibe for the app
